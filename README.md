## The pitch

> I run a delivery startup with 10,000 couriers who work for breadcrumbs and never call in sick. We're raising a seed round. Literally.

133 characters, one line.

## Why this line

A real elevator pitch in the pigeon's own voice: a delivery startup whose
courier fleet is paid in breadcrumbs and never calls in sick, with the turn
on the last two words — "a seed round. Literally." — the startup cliche made
literal, because a pigeon's seed round is actual seed.

## How it works

`main.py` (pure standard library) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), validating the
RULES.txt gate first (UTF-8, 1–200 characters, single line, not only
whitespace, no control characters) and re-validating the written file
byte-for-byte afterwards.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
